# 实验二模型与交互统一规格

实验名称：种子萌发时释放二氧化碳  
所属系列：植物的呼吸作用——三个证据的交互式演示实验  
文档状态：设计基线，等待用户逐项模型验收  
适用范围：模型制作、模型审核台及后续实验二正式网页  

> 本文件是实验二模型的唯一尺寸与交互基线。后续修改必须先更新本文件，再修改模型。已经通过用户确认的模型，不得在整合过程中擅自改变。

## 1. 已确认的总体要求

1. 甲组使用萌发种子，乙组使用煮熟后冷却至室温的种子。
2. 甲、乙两组分别拥有独立材料，不跨组共用。
3. 甲、乙各使用一只独立注水烧杯。
4. 不制作可见的试管固定支座。
5. 未组装时，试管、导气管、漏斗和橡胶塞分别平放在实验台材料区。
6. 设置“一键组装”按钮，按钮只完成装置准备，不代替注水、排气和观察现象。
7. 甲组实验先完成，保留甲组现象，再操作乙组。
8. 甲乙现象一直保持，直到用户点击“结束实验并归位”。
9. 场景允许自由缩放和平移，步骤切换和动画不得自动抢占镜头。
10. 所有器材模型保持独立文件、独立状态和独立碰撞区域，便于后期逐个修改。

## 2. 建模单位与坐标

- Three.js 原始建模单位：`1 unit ≈ 4 cm`。
- `X`：左右方向。
- `Y`：竖直方向。
- `Z`：前后方向。
- 器材底部中心作为模型局部原点。
- 正式网页推荐统一缩放：`0.55`。
- 甲乙使用相同尺寸，乙组只改变种子状态及装置朝向，不改变模型比例。
- 所有尺寸必须读取统一常量，禁止在动画中临时拉伸模型。

统一常量文件：`models/constants.js`。

结构要求：

- `tubularSegments ≥ 96`。
- 禁止用多个直管拼接成明显折角。

独立交互：

- 整根导气管作为刚性整体拖动，拖动中不变形。
- 同时检测橡胶塞孔和试管口两个连接点。
- 只有两个端点同时进入有效范围才允许组装成功。
- 自动校正耗时 `0.45s`。
- 只有一端对准时返回材料区，不得强行吸附。

## 11. 注水烧杯

甲、乙各一只独立烧杯，不能跨组使用。

| 参数 | 数值 |
|---|---:|
| 杯口外径 | 1.24 |
| 杯底外径 | 1.04 |
| 高度 | 1.66 |
| 壁厚 | 0.06 |
| 初始水量 | 容积的 78% |
| 倒完剩余水量 | 0% |

有效倾倒条件：

- 烧杯口最低点位于漏斗口上方 `0.18–0.25`。
- 烧杯口与漏斗中心水平偏差不超过 `0.12`。
- 倾倒角度为 `58°–65°`。
- 烧杯不得和漏斗相互穿插。
- 甲烧杯从甲组外侧进入，乙烧杯从乙组外侧进入。

错误位置：

- 不出现水流。
- 不减少烧杯水量。
- 不增加瓶内水位。
- 松手后在 `0.45s` 内返回材料区。

## 12. 水流

| 参数 | 数值 |
|---|---:|
| 水流直径 | 0.07–0.10 |
| 几何分段 | 24 |
| 横向摆动 | ≤0.025 |
| 形成时间 | 0.18–0.35s |
| 停止时间 | 0.22–0.25s |

真实性要求：

- 水流起点实时绑定烧杯口最低点。
- 水流终点实时绑定漏斗锥体中心。
- 水流受重力向下弯曲，不能表现成固定直杆。
- 烧杯移动时，水流起点必须同步移动。
- 倾斜时烧杯内自由液面总体保持水平。
- 水流停止后允许出现少量自然余滴。

## 13. 瓶内水体

| 参数 | 数值 |
|---|---:|
| 初始水位 | 0 |
| 最终水位 | 3.35 |
| 最大半径 | 1.32 |
| 底部高度 | 0.18 |
| 距导气管入口 | ≥1.10 |

几何规则：

- 水体必须根据瓶子内部轮廓改变半径。
- 禁止使用穿过瓶肩和瓶壁的完整圆柱。
- 水面始终保持水平。

统一进度 `fillProgress: 0–1` 同时控制：

1. 烧杯水量下降。
2. 水流强度。
3. 瓶内水位上升。
4. 种子轻微松动。
5. 瓶内气体排出。
6. 试管气泡生成。

不得出现烧杯已经空了但瓶内水位仍单独上升的问题。

## 14. 气泡系统

| 参数 | 数值 |
|---|---:|
| 同屏气泡数量 | 18–24 个 |
| 气泡直径 | 0.035–0.080 |
| 生成间隔 | 0.12–0.28s |
| 单个上升时间 | 0.8–1.2s |
| 横向摆动 | ±0.04 |
| 起点 | 导气管真实出气口 |
| 终点 | 石灰水液面 |

单个气泡动画：

1. 在导气管出气口形成。
2. `0.10s` 内从小到大。
3. 沿轻微弯曲轨迹上升。
4. 接近液面时稍微放大。
5. 到达液面后消失。
6. 液面出现轻微波纹。

气泡不得从试管底部凭空生成，也不得穿过试管壁。

## 15. 未组装材料布局

材料区只负责陈列和取用，器材之间不得遮挡。

- 广口瓶竖直放置。
- 种子已经装在对应瓶内。
- 橡胶塞平放。
- 长颈漏斗平放或低位侧放，不能竖直挡住瓶子。
- 弯曲导气管平放，整段可见。
- 试管横放，管口方向明确。
- 甲乙烧杯分别放在各组外侧。
- 两组之间保留安全空白区域。

## 16. 一键组装动画

按钮名称：`一键组装`。

按钮只完成装置准备，不执行注水和实验现象。

| 阶段 | 动作 | 时间 |
|---|---|---:|
| 1 | 双孔塞移动到瓶口上方并压入 | 0.45s |
| 2 | 漏斗保持横放升高、空中转为竖直并从上向下插入漏斗孔 | 0.90s |
| 3 | 试管从横放状态升起并转为竖直 | 0.50s |
| 4 | 导气管升起并校正两个端点 | 0.55s |
| 5 | 导气管两端分别进入瓶塞孔和试管 | 0.45s |
| 6 | 检查间距并开放注水交互 | 0.20s |

总时间：约 `3.05s`。

动画规则：

- 甲乙同时组装，但路径互不交叉。
- 每件模型读取自己的起点和终点。
- 不得突然瞬移或穿过其他器材。
- 组装过程中不得改变模型尺寸。
- 试管组装后直接落在实验台面，不显示支座。
- 已经完成组装时，重复点击不得重新生成器材。

## 17. 倒水排气动画

单组完整倒水演示约 `7.0s`。

| 阶段 | 时间 |
|---|---:|
| 用户拖动烧杯至漏斗上方 | 用户控制 |
| 有效位置微调 | 0.20s |
| 烧杯倾斜 | 0.45s |
| 水流形成 | 0.35s |
| 持续注水 | 5.20s |
| 水流停止 | 0.25s |
| 烧杯恢复竖直 | 0.35s |
| 烧杯返回组内材料位 | 0.55s |

排气过程：

- 注水开始约 `0.8s` 后，气泡进入试管。
- 气体排出与瓶内水位上升读取同一进度。
- 甲组气泡出现约 `1s` 后，石灰水开始变浑浊。
- 乙组气泡正常出现，但石灰水保持澄清。

## 18. 甲乙操作顺序

1. 点击“一键组装”。
2. 用户拖动甲组烧杯完成甲组注水排气。
3. 甲组石灰水逐渐变浑浊。
4. 保持甲组装置和浑浊现象。
5. 用户拖动乙组烧杯完成乙组注水排气。
6. 乙组石灰水保持澄清。
7. 同时保留甲乙主场景和细节对比。
8. 用户点击“结束实验并归位”。
9. 停止气泡和进行中的动画，甲乙材料分别返回原位。

## 19. 状态数据

每件器材至少保存：

- `homePosition`
- `homeQuaternion`
- `operationPosition`
- `currentGroup`
- `isDragging`
- `isInstalled`
- `isAnimating`
- `interactionEnabled`

实验整体至少保存：

- `assemblyState`
- `activeGroup`
- `fillProgress.A/B`
- `gasProgress.A/B`
- `cloudiness.A/B`
- `observed.A/B`
- `finished`
- `actionToken`

状态规则：

- 甲乙身份从开始到结束不可混淆。
- 取消或跳步时先终止旧动画，再重建目标状态。
- 复位必须清除液量、气泡、浑浊、组装关系和计时器。
- 快速重复点击不得生成重复模型。
- 归位不得穿过瓶体或其他器材。

## 20. 镜头与操作控制

- 空白区域拖动：平移或观察视角。
- 滚轮或触控缩放：自由缩放。
- 器材拖动与场景平移必须互斥。
- 步骤变化、一键组装、注水和现象变化均不得自动改变镜头。
- 提供独立“复位视图”按钮。
- 放大后选取范围和吸附位置必须保持准确。

## 21. 固定禁止事项

- 禁止重新制作已经确认的广口瓶和单粒种子近似模型。
- 禁止添加可见试管架或透明支座。
- 禁止把漏斗杆做成不透明白棍。
- 禁止导气管出现明显折角、悬空或端点穿插。
- 禁止水流从错误位置产生。
- 禁止使用固定水柱代替动态水流。
- 禁止甲乙共用同一只烧杯。
- 禁止乙组没有气泡。
- 禁止石灰水一帧内突然变成最终浑浊状态。
- 禁止一键组装自动完成注水或实验结论。
- 禁止用按钮成功掩盖直接拖动失效。
- 禁止模型整合时改变已确认尺寸。
- 禁止未实际验证就标记为用户确认。
