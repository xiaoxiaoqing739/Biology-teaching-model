## 交互原型 I-03：叶片结构智能组装

- [x] 直接复用已确认的真实模型组件。
- [x] 上下表皮固定为相同的 6 行×9 列，每层 54 个单元。
- [x] 为表皮模型增加版本标识，避免浏览器缓存旧版 5×8 上限。
- [x] 上下表皮尺寸适当放大，并自动锁定对齐。
- [x] 下表皮支持配置 0—3 个气孔。
- [x] 上、下表皮叶绿体数量可分别调节，细胞颜色随数量产生明显变化。
- [x] 颜色联动覆盖细胞壁、细胞质和液泡；0 与 24 个叶绿体可明显区分。
- [x] 右侧参数变化实时显示细胞外形和叶绿体数量。
- [x] 取消单个模型旋转、拖放和操作轴，避免与整体视角移动误触。
- [x] 中间组织从 0 层开始逐层搭建，最多增加到 6 层。
- [x] 0 行且无叶脉时上下表皮贴合；保留叶脉时仅留出叶脉厚度。
- [x] 规则铺满模式按 6×9 网格整齐排列，无叶脉时每行 54 个细胞。
- [x] 随机不铺满模式支持 40%—88% 疏松密度和重新随机。
- [x] 每层独立保存细胞形态、尺寸、叶绿体数量、铺设方式和疏松度。
- [x] 支持规律层与随机层混合叠加，用于表现栅栏组织和海绵组织差异。
- [x] 所有叶肉细胞均限制在上下表皮共同边界内，避免尺寸溢出。
- [x] 支持无、细、中、粗四档叶脉，并为叶脉自动预留空间。
- [x] 叶脉默认使用粗档，横向长度固定等于表皮宽度。
- [x] 去除透明维管束鞘两端的球形端盖，避免叶脉两端出现透明凸出结构。
- [x] 支持清空中间组织和撤销。
- [x] 点击“确认模型”后锁定学生当前搭建结果，再由“开始交互”启动同步演示。
- [x] 叶脉木质部与韧皮部运输粒子同步运动；气孔开度由用户连续控制，气体粒子只从开孔进出。
- [x] 支持暂停、继续、重新演示及 0.5×、1×、1.5×、2×速度。
