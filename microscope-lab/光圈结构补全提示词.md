```text
6 片叶片的几何、姿态与开合角全部按以下数值落地，不要再自由发挥：

参数常量：
- N = 6（叶片数）
- ROOT_R = .44（铆钉所在圆周半径，紧贴外圈内壁 .44）
- LEAF_LEN = .55（叶片从铆钉伸出的有效长度，必须 > ROOT_R 才能在关闭时穿过圆心）
- HALF_ANGLE = π/6 = 30°（单片扇形半张角，6×60° 圆周刚好拼满 360° 并互相重叠 0）
- Z_STEP_BASE = .05（叶片根部在 Y 方向逐级下沉的基准）
- Z_STEP_INC = .012（每片下沉增量）
- APERTURE_MAX_RAD = Math.PI/3 = 60°（aperture 0→4 对应叶片绕铆钉旋转的总角度）
- 每片逆时针 vs 顺时针：6 片全部用同一旋转方向（不交替），靠圆周错位自动形成六边形光孔
```

```
叶片 mesh 的姿态（决定叶尖朝向和躺平面）：
- `leaf.rotation.x = -Math.PI/2;`（躺平到 XZ 水平面，叶尖从朝上→水平指向 +X 方向）
- `pivot.rotation.y = a - Math.PI/2;`（让 pivot 旋转后，叶尖从 +X 转向圆心方向）
   验证：a=0 时 pivot 在 (ROOT_R, 0)，rotation.y=-π/2 后 pivot 局部 +X 变成世界 -X，即叶尖从 (ROOT_R,0) 指向 (0,0) ✓
   a=π/3 时 pivot 在 (cos60°·R, sin60°·R)，rotation.y=π/3-π/2=-π/6，叶尖沿圆周切线方向 -π/2 + a 转后指向圆心 ✓

闭孔角基准 irisBase[i]：每个 pivot 闭孔姿态 rotation.y 的基准值：
```
irisBase[i] = a - Math.PI/2;   // 即与初始姿态一致 = 闭孔姿态
```
当 aperture=0 时所有叶片叶尖都指向圆心，6 片叶尖在 (0,0) 重合 → 孔径≈0（关闭）。

```

irisPivots.forEach((p,i)=>{ p.rotation.y = irisBase[i] + theta; });

```
═══════════════ 四、整段参考实现（可直接复制粘贴进 model.js 替换第 86 行整段）═══════════════

```
const IRIS_N=6,IRIS_ROOT_R=.44,IRIS_LEN=.55,IRIS_HALF=Math.PI/6;
const IRIS_APERTURE_MAX=Math.PI/3;
const diaphragm=group(condenser,[0,-.42,0]);
const housing=ring(.50,.06,M.metal,diaphragm,[0,0,0]);
const irisPivots=[],irisBase=[];
for(let i=0;i<IRIS_N;i++){
  const a=(i/IRIS_N)*TAU;
  const pivot=group(diaphragm,[Math.cos(a)*IRIS_ROOT_R,-(.05+i*.012),Math.sin(a)*IRIS_ROOT_R]);
  const s=new THREE.Shape();
  s.moveTo(0,0);
  s.absarc(0,0,IRIS_LEN,-IRIS_HALF,IRIS_HALF,false);
  s.lineTo(0,0);
  s.closePath();
  const leaf=mesh(new THREE.ShapeGeometry(s,32),M.dark,pivot);
  leaf.rotation.x=-Math.PI/2;
  irisBase[i]=a-Math.PI/2;
  pivot.rotation.y=irisBase[i];
  irisPivots.push(pivot);
}
const lever=box(.70,.06,.08,M.metal,diaphragm,[.42,0,.12]);
const leverKnob=cyl(.08,.10,M.metal,lever,[.32,0,0]);leverKnob.rotation.z=Math.PI/2;
tag(diaphragm,'diaphragm');
```

注意：`housing` 用现成的 `ring(r,t,mat,parent,pos)` 辅助函数（它内部会自动 rotation.x=π/2 躺平），所以无需手动再设旋转。
```
