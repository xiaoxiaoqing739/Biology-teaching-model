═══════════════ 一、粗/细准焦螺旋：同轴「一大一小包裹」的黑色螺纹圆柱 ═══════════════

【目标形态（对照真实显微镜）】
粗准焦螺旋与细准焦螺旋是**同轴共心**的两件套，不是并排、不是分离：
- 转轴沿 X 轴从镜臂内部横向伸出；
- 粗准焦螺旋 = 大直径、厚实的**黑色圆柱旋钮**，外缘一圈明显滚花（螺纹防滑纹）；
- 细准焦螺旋 = 小直径、较薄的**黑色圆柱旋钮**，同轴共心，紧贴在粗调大轮**外侧**端面（视觉上"大轮包小轮"）；
- 两者都绕同一根 X 轴旋转，粗调大轮直径约为细调小轮的 2 倍。

【当前 code（需修改的地方）】
```
const coarse=group(root,[0,2.20,-1.75]);
const axle=cyl(.12,1.82,M.metal,coarse);axle.rotation.z=Math.PI/2;
const coarseWheels=[],fineWheels=[];
[-1,1].forEach(side=>{const cw=group(coarse,[side*.57,0,0]);
  const c=lathe([[.35,-.12],[.48,-.08],[.48,.08],[.35,.12]],M.rubber,cw);c.rotation.z=Math.PI/2;
  knurl(cw,.47,32,.18);coarseWheels.push(cw)});tag(coarse,'coarse');
const fineRoot=group(coarse);
[-1,1].forEach(side=>{const fw=group(fineRoot,[side*.82,0,0]);
  const f=lathe([[.18,-.09],[.245,-.06],[.245,.06],[.18,.09]],M.rubber,fw);f.rotation.z=Math.PI/2;
  knurl(fw,.24,24,.13);cyl(.11,.03,M.metal,fw,[side*.10,0,0]);fineWheels.push(fw)});tag(fineRoot,'fine');
```

【修改要求】
1. 形状改「厚实圆柱」：现在用 lathe 挤出的是扁盘（轴向厚度仅 .24/.18），不够像真实手轮。
   - 粗调大轮：改成一个厚实的黑色圆柱旋钮，半径约 .47~.50、轴向厚度约 .30~.34；外缘滚花要明显（齿数 ≥ 32，齿高加大，可以换用更粗的 knurl）。
   - 细调小轮：半径约 .23~.26、轴向厚度约 .16~.20；外缘滚花明显。
2. 「大包小」同轴共心：细调小轮与粗调大轮**同轴紧贴**（共一根 X 轴），细调小轮位于粗调大轮外侧端面，两者中心在同一条轴线上、不要留明显横向间隙。
3. 实体黑色：两轮都用黑色（沿用 M.rubber 0x101b1d 的近黑色橡胶质感，或改用纯黑 M.black），保证渲染出来是"实体黑色"，不是深绿/灰。
4. 保留旋转联动：animate() 里 coarseWheels/fineWheels 仍绕 X 轴旋转（coarse 每格粗调、fine 每格微调），改形状后不要弄断联动。

═══════════════ 二、横向/纵向手轮：上下排列「一大一小」的黑色螺纹圆柱 + 方向修正 ═══════════════

【目标形态】
载物台右前下方伸出一根竖轴，轴端两个**上下叠放**的手轮：
- 上方手轮 = **较大**直径的黑色滚花圆柱；
- 下方手轮 = **较小**直径的黑色滚花圆柱；
- 两者都是实体黑色、外缘滚花（螺纹防滑纹）、绕竖轴（Y 轴）旋转。

【当前 code（需修改的地方）】
```
const knobUpperMat=new THREE.MeshStandardMaterial({color:0x143b3d,metalness:.35,roughness:.38});   // ← 深绿青，改黑
const knobLowerMat=new THREE.MeshStandardMaterial({color:0x30595a,metalness:.42,roughness:.36});   // ← 灰青，改黑
...
const xyX=group(xy,[1.40,-.12,-.45]);xyX.rotation.z=Math.PI/2; ... cyl(.20,.14,knobUpperMat,spinXVisual);knurl(spinXVisual,.20,24,.14);
const xyY=group(xy,[1.40,-.46,-.45]);xyY.rotation.z=Math.PI/2; ... cyl(.18,.14,knobLowerMat,spinYVisual);knurl(spinYVisual,.18,22,.14);
```

【修改要求】
1. 颜色改「实体黑色」：把 knobUpperMat / knobLowerMat 的颜色从 0x143b3d、0x30595a 改成黑色（如近黑 0x15181a，或直接用 M.rubber 的黑色橡胶质感）。
2. 大小差异拉大：现在上下两轮半径只差 0.02（.20 vs .18），几乎一样大，看不出"一大一小"。
   → 上方手轮半径增大到约 .24，下方手轮半径缩小到约 .14，二者形成明显的大小对比。
3. 滚花螺纹明显：外缘滚花齿数/齿高加大，使"螺纹"可见。
4. 方向修正（重点，资料已查证）：
   - **上方（较大）手轮 = 纵向 = 前后移动**（对应 state.slideY / yRail 前后移动）；
   - **下方（较小）手轮 = 横向 = 左右移动**（对应 state.slideX / xRail 左右移动）。
   - 当前 animate() 里写的是：
     `spinX.rotation.x=state.slideX*8; spinY.rotation.x=state.slideY*8;`  ← 方向反了（上层 spinX 联动了左右、下层 spinY 联动了前后）。
   - 改成：上方手轮联动 slideY（前后），下方手轮联动 slideX（左右）。即交换两个联动的目标：
     `spinX`（现在挂在上层大轮位置的组）改联动 `state.slideY`，`spinY`（下层小轮）改联动 `state.slideX`；
     或直接把上层手轮的旋转绑定 slideY、下层手轮的旋转绑定 slideX（变量名可相应改名，让"上=纵/前后、下=横/左右"一眼可读）。

═══════════════ 三、升降机构在镜臂内侧、焦螺旋在镜臂与升降结构之间 ═══════════════

【当前 code 参考】
- 镜臂 arm：root[.32,0,0]，armBody 为 cast 拉伸的 C 形轮廓。
- 升降导轨 carriage：`[-.25,.25].forEach(x=>box(.06,2.06,.08,M.metal,carriage,[x,2.8,-1.35]))`，外加透明盖板 cv1(z=-1.26)/cv2(z=-1.78)。
- 齿条 rack：`group(moving,[0,2.82,-1.50])`，box(.32,1.75,.09,brass) + 27 个齿。
- 焦螺旋 coarse：`group(root,[0,2.20,-1.75])`，小齿轮 pinion 也在 root[0,2.20,-1.75]。

【修改要求】
1. 核对并修正三者的前后(Z)层次：从外到内应为「镜臂外侧面 → 粗/细焦螺旋（大轮小轮）→ 升降齿条/导轨」。即升降机构（导轨+齿条）要**贴镜臂内侧**，焦螺旋轴要**位于镜臂外侧与升降机构之间**，小齿轮 pinion 与齿条 rack 在同一 Z 平面（当前都是 -1.50/-1.75 附近）啮合、无脱开。
2. 升降机构应藏在镜臂内侧、从外侧只看到镜臂与伸出的焦螺旋手轮，不出现齿条/导轨悬空外露、错位。
