> 坐标约定：**Y 轴向上，Z 轴朝观察者**；前置光路沿 +Z，后方传动机构沿 -Z。

## 给 Codex 的修复提示词（整段复制）

```text
你是 Three.js 工程师。继续修改 model.js，本轮只修三件事：(1) 双目镜筒出现"透明/空心/透光"要改成实心不透明外壳；(2) 调横/纵手轮时压片夹要随玻片一起移动；(3) 参考附带的 threejs 参考文件补充「光源开关开灯→出现光束→亮度可调」。只改 model.js，不动 physics.mjs、main.js，不新增别的功能。

坐标系：Y 向上，Z 朝观察者，前置光路沿 +Z，后方传动沿 -Z。

═══════════════ 一、双目镜筒：实心不透明 ═══════════════

【当前错误/根因】
- 双目头 tube 组在 root[0,4.93,.10]，内部含：分光棱镜壳 prism（cast 挤出）、过渡段 cyl、桥 bridge（box）、两枚目镜 eyepiece。
- 目镜筒身是用 lathe() 生成的 LatheGeometry：`lathe([[.20,0],[.29,0],[.29,.52],[.24,.57],[.24,.66]],M.white,e)`。
  LatheGeometry 只生成「绕 Y 轴旋转的侧面」，**不封两端**；M.white 是 FrontSide 单面材质，背面不可见。
  → 结果：目镜筒顶部/底部开口、从顶部或斜内侧看是中空的，表现为"透明管/透明镜筒"。

【要改成】
让目镜筒（以及其它所有用 lathe() 生成的开口筒状/壳状部件）成为**实心不透明外壳**，颜色沿用乳白 M.white / 深灰 M.dark，外形不变：
1. 目镜筒身 lathe([[.20,0],[.29,0],[.29,.52],[.24,.57],[.24,.66]])：
   - 顶部补盖：CircleGeometry(r=.24)，rotation.x=-Math.PI/2，放在局部 y=.66；
   - 底部补盖：CircleGeometry(r=.29)，rotation.x=Math.PI/2，放在局部 y=0；
   （也可改用多段 CylinderGeometry 堆出同样的台阶外形，只要封闭即可。）
2. 眼罩 rubber 的 lathe 同样封端，并检查顶部镜片 cyl(...M.lens...) 是否把筒口盖严。
3. 通查文件里所有 lathe() 生成的筒/壳，凡中空开口都要封端或用封闭几何，确保外壳任意角度看都是实心、不透明、无内部透出。

【验收】
旋转到目镜口、侧面、斜下方等多个角度，双目镜筒始终是实心乳白/深灰外壳，看不到内部空心或背景透光；镜筒的倾斜角度、瞳距桥(55·64·75)、目镜倍率标签等既有结构不变。

═══════════════ 二、压片夹：随横/纵手轮一起移动 ═══════════════

【当前错误/根因】
现有层级（model.js）：
  stage = group(moving,[0,2.74,.30])          // 机械载物台，随升降
  xy    = group(stage)
  yRail = group(xy,[0,0,0])                    // 纵向轨：驱动玻片前后(Z)移动
  xRail = group(yRail,[0,0,-.30])              // 横向轨：驱动玻片左右(X)移动
  slide = group(xRail,[0,.10,0])               // 玻片
  clips = group(stage)  在 [±.82,.11,-.32]     // ← 错误：挂在 stage，静止不动
animate() 里：
  xRail.position.x → state.slideX*0.9         // 横向手轮
  yRail.position.z → state.slideY*0.9         // 纵向手轮
玻片挂在 xRail 下会随两个方向一起动，但压片夹挂在 stage 上，所以玻片动、压片夹不动。

【要改成】
让压片夹与玻片作为一个整体同步移动——把压片夹挂到 xRail 下（与 slide 同级），二者同时继承 xRail 的 X 移动 + yRail 的 Z 移动。
1. 把 `const clips=group(stage)` 改为 `const clips=group(xRail)`（注意：clip 的定义必须移到 xRail 定义之后，当前它在 xRail 之前，需下移位置）。
2. 坐标换算：clips 原在 stage 局部 [±.82,.11,-.32]；xRail 原点在 stage 局部为 [0,0,-.30]。
   → 移到 xRail 下后，位置改为 [±.82,.11,-.02]（Z 方向 -0.32 减去 xRail 的 -0.30 偏移）。
3. 其余不变：每枚压片夹仍是竖杆 cyl(.085,.12) + 金属叶片 box(.12,.025,.95) 沿 Z 跨过玻片，叶片 rotation.y = 左夹 -0.18 / 右夹 +0.18，clipPieces 数组与 setSpecimenPulse 动画保留。

【验收】
拖动横向/纵向手轮（或玻片滑杆、画布拖动）时，玻片与两枚压片夹作为一个整体同步平移，压片夹始终压在玻片左右两缘、不脱开；载物台本体与通光孔保持不动。

═══════════════ 三、光源：开灯→光束，亮度可调（参考 threejs 文件） ═══════════════

【现状（已可用，不要重做）】
- power 组（底座右前 root[.93,.61,1.08]）已有：跷跷板开关 rocker（control='power'）、亮度旋钮 bright（control='brightness'）、指示灯 led。
- 点击/拖拽交互已接好：点开关切换 state.power，拖亮度旋钮调 state.intensity(0-100)；UI 侧 #powerButton 与 #intensity 滑杆也已绑定。
- lamp 组（root[0,.57,.30]）已有：灯座 lathe + 灯泡 bulb（emissive 已随 power 发光）+ 顶部玻璃 cyl(.29,.025,M.glass,lamp,[0,.36,0])。

【缺少的：开灯后的光束、透镜本身发光、照亮标本的点光源】
参考文件（threejs-microscope.html）的电光源做法，按 model.js 的坐标体系接入：
1. 灯罩发光的透镜 lens：
   - lamp 组的顶部玻璃 cyl(.29,.025,M.glass,…) 换成/叠加一层 emissive 透镜：
     `new THREE.MeshStandardMaterial({color:'#9db8cc', emissive:'#bfe0ff', emissiveIntensity:0})`
   - 记为 lampLensMat，开灯后 emissiveIntensity 随亮度变化。
2. 光柱（光束）lightCone：
   - 材质：`new THREE.MeshBasicMaterial({color:'#cfe8ff', transparent:true, opacity:0, blending:THREE.AdditiveBlending, depthWrite:false, side:THREE.DoubleSide, fog:false})`
   - 几何：`new THREE.CylinderGeometry(0.16, 0.20, 高度, 32, 1, true)`（开口锥形，下宽上窄或下窄上宽据效果微调）。
   - 位置：沿光轴 z≈.30，从灯罩上表面（灯罩在 lamp 局部 [0,.36,0]，世界 y≈.93）向上射到载物台通光孔下方（通光孔世界 y≈2.8），高度约 1.8~1.9、中心放 y≈1.8；可挂 lamp 下或 root 下，务必与灯罩、聚光镜、通光孔同轴(z=.30)。
3. 点光源 lampLight（照亮标本/聚光镜）：
   - `new THREE.PointLight('#dff2ff', 0, 3.2, 1.6)`，放在灯罩上方（如 root[0,1.2,.30] 或 lamp 局部 [0,0.5,0]）。
4. animate() 联动（在现有 bulb/rocker/led 那行附近补上，用现成的平滑因子 l 平滑过渡，避免骤变）：
   lampLensMat.emissiveIntensity = state.power ? state.intensity/100*2.6 : 0;
   coneMat.opacity = 缓动到 (state.power ? 0.04 + state.intensity/100*0.16 : 0);
   lampLight.intensity   = state.power ? state.intensity/100*2.5 : 0;
   （关灯：光柱 opacity=0、透镜 emissiveIntensity=0、点光源 intensity=0。）
5. 可选：参考文件里的电源指示灯环 powerRing（TorusGeometry 平放，emissive 颜色关灯红/开灯绿、emissiveIntensity 平滑 0.15↔1.6），加在现有 power 开关旁增强"开关状态"的可视性，但不要破坏现有 rocker/bright 的 userData.control 交互。

【验收】
点击电源开关（或 UI 电源按钮）开灯：底座光源透镜亮起、竖直光柱出现、标本区明显被照亮；拖动亮度旋钮或亮度滑杆，光柱浓淡、透镜亮度、点光源强度三者同步连续变化；关灯后光柱、透镜发光、点光源全部熄灭，仅剩环境光下的镜身。
```

## 附：本次定位到的根因清单（供你对照验收，可不发给 Codex）

| # | 问题 | 根因 | 修复要点 |
|---|------|------|----------|
| 1 | 双目镜筒"透明/空心" | 目镜筒等用 `lathe()` 生成 LatheGeometry（开放旋转面、无端盖）+ `M.white` 单面材质，背面不可见 → 中空透光 | 封两端（CircleGeometry 顶/底盖）或改封闭几何，外壳实心不透明乳白/深灰 |
