═══════════════ 一、镜臂 arm：白色矩形截面立柱 + 阶梯折角 ═══════════════

【当前 code（第 55 行附近）】
```
const arm=group(root,[.32,0,0]);
const armBody=cast([[-1.96,.55],[-1.60,.55],[-1.60,2.9],[-1.60,4.58],[.35,4.73],[.4,5.12],[-1.30,5.32],[-1.96,4.88]],.64,arm,[0,2.935,0],'arm',.10);
armBody.rotation.y=-Math.PI/2;
box(.54,.20,.65,M.white,arm,[0,3.87,-1.47]);
tag(arm,'arm');
```

【问题根因】
现在的 armBody 是一段向前弯折、顶部带尖角/镂空提手孔效果的**异形薄片轮廓**，还要 `rotation.y=-Math.PI/2` 翻转 + 位置补 y=2.935，整体又薄又复杂，和真实镜臂（矩形截面粗立柱）不符。

【修改要求】
1. 把镜臂改成**一根白色粗壮的矩形截面立柱**（用 box 或 cast 矩形轮廓，继续用 M.white），从镜座后部（-Z 侧）向上、略微向后下方延伸；整体呈「L 形折角 + 阶梯过渡」，棱角清晰、有轻微倒角即可，**去掉镂空提手孔、去掉顶部向前伸的尖角**。
2. 顶部做一个**阶梯状折角块**，托住上方的分光头（tube / prism）；镜臂下端与镜座 base 平滑衔接、不悬空。
3. 对齐锚点（务必核对）：
   - 镜臂底部落在镜座 base 后部顶面附近（base 在 root[0,.49,0]）；
   - 镜臂顶部台阶与分光头 tube（root[0,4.93,.10]，X=0）居中衔接，不要让镜臂相对分光头出现左右错位（当前 arm 组在 x=.32，而 tube 在 x=0，需把立柱中心对到分光头中心线 x≈0）。
4. 保留 `tag(arm,'arm')` 的选中/轮显；animate() 里没有对 arm 的联动，所以只要位置/形态改对即可，不涉及动画公式。
