═══════════════ 一、双目头分光头（棱镜盒）形状修整 ═══════════════

【当前 code（第 82 行附近）】
```
const tube=group(root,[0,4.93,.10]);
const prism=cast([[-.67,-.32],[.67,-.32],[.75,.20],[.44,.62],[-.44,.62],[-.75,.20]],.76,tube,[0,0,-.40],'tube',.09);
prism.rotation.y=Math.PI/2;
cyl(.53,.16,M.dark,tube,[0,-.34,0]);
cyl(.48,.12,M.white,tube,[0,-.43,0]);
const bridge=group(tube,[0,.29,.44]);bridge.rotation.x=Math.PI/4;
box(1.65,.17,.42,M.dark,bridge);
```

【问题根因】
1. 轮廓六边形在中间（y=.20 处）外扩到 ±.75，比上下都宽（底 ±.67、顶 ±.44），形成一个"束腰花瓶"形的中间鼓包，不像真实的梯形棱镜盒。真实棱镜盒是**上窄下宽的光滑梯形/台体**，中间不放肩、不鼓包。
2. `cast()` 会 `g.center()` 居中，再 `prism.rotation.y=Math.PI/2`（绕 Y 转 180°）、位置放在 tube 局部 [0,0,-.40]，导致棱镜盒相对转轴/观察者前后偏置、视觉上歪斜、和下方脖子与镜臂对不齐。

【修改要求】
1. 把 prism 轮廓改成**干净的对称梯形**（宽底、窄顶，两侧斜边直线），例如：
   `cast([[-.75,-.32],[.75,-.32],[.44,.62],[-.44,.62]],.76,tube,[0,0,-.40],'tube',.09)`
   或保留轻微肩部但**去掉 mid 鼓包**（保证 y=.20 处宽度 ≤ 底宽）。
2. 核对 prism 的居中与朝向：`cast` 已居中，不要再叠加导致前后偏移的 rotation 与位移；保证棱镜盒左右对称、底面与下方脖子（cyl）平滑衔接、顶面与 bridge 自然过渡。
3. 脖子过渡：下方 `cyl(.53,.16,M.dark,…)` + `cyl(.48,.12,M.white,…)` 两层短柱，让它们呈**上宽下窄的锥度**贴住镜臂顶部，不要出现粗细突变或错位的"细脖子"。
4. 保持 bridge（瞳距调节桥）与 eyepiece 挂在 tube 下、可随 ipd 联动，不被本轮改动破坏。

═══════════════ 二、目镜镜筒透明（能看穿）修复 ═══════════════

【当前 code（第 83 行附近）】
```
const e=group(eyeRoot,[side*.52,0,0]);
lathe([[.20,0],[.29,0],[.29,.52],[.24,.57],[.24,.66]],M.white,e);
lathe([[.20,0],[.235,0],[.235,.35],[.30,.39],[.31,.52],[.22,.55],[.195,.50]],M.rubber,e,[0,.52,0]);
cyl(.193,.016,M.lens,e,[0,1.035,0]);
```

【问题根因】
白色目镜筒由 `lathe()` 生成，首尾点分别落在 r=.20 / r=.24，**没有封到轴心**，是两端开口的筒壁；虽然 lathe 辅助函数尝试补了 CircleGeometry 圆片，但只补了内孔半径那一圈，衬托面未完全闭合，加上材质是单面 `FrontSide`，导致从上方/侧面能直接看穿筒身、看到内壁背面的空洞（这就是"依旧透明"）。

【修改要求】
1. 保证目镜白色镜筒**两端完全闭合**（不透光、无内壁空洞）。二选一：
   - 方案 A（推荐）：把白色镜筒从 `lathe` 改为**闭合的挤出/车削**——把轮廓首尾点改到轴心闭合：
     `lathe([[0,0],[.29,0],[.29,.52],[.24,.57],[.24,.66],[0,.66]],M.white,e)`
     （首 [0,0]、尾 [0,.66] 收口到轴心，LatheGeometry 自动封闭两端。）
   - 方案 B：保留现轮廓，但在两端**各加一整片与外侧半径等大的圆片**（bottom 用 r=.29、top 用 r=.24 的 CircleGeometry），并确保朝向朝外。
2. 材质设为**实体不透明白色**：确认 `M.white`（0xe1e3df，MeshStandardMaterial）`transparent` 为 false；若仍有透底，可给该筒材质加 `side:THREE.DoubleSide` 兜底。
3. 眼睛透镜 `cyl(.193,.016,M.lens,…)` 应正好填住目镜筒顶端开口（不悬空、不留缝），眼罩（M.rubber 那层）套在其外，保证从上往下看不到筒内空洞。
4. 保留 eyepiece 的 ipd 水平移动与 diopter 环，不影响 `tag(eyeRoot,'eyepiece')` 的选中/轮显。

═══════════════ 三、装片（玻片）透明度过高 + 标本位置 ═══════════════

【当前 code（第 68 行附近）】
```
const slide=group(xRail,[0,.10,0]);
const slideGlass=box(1.9,.035,.68,M.glass,slide);
box(.43,.012,.60,new THREE.MeshStandardMaterial({color:0xf2efe0,roughness:.8}),slide,[-.68,.026,0]);
label('SPECIMEN',slide,[-.68,.035,0],.38,.10);
tag(slide,'slide');
```
其中 `M.glass` = `MeshPhysicalMaterial({color:0xa8d7d5,transparent:true,opacity:.35,roughness:.05,side:DoubleSide,depthWrite:false})`。

【问题根因】
1. `M.glass` 的 `opacity:.35` 太低、`depthWrite:false`，导致玻片几乎隐形、又被后面物体透过来，视觉上"太透明"、没有玻璃实体的存在感。
2. 标本（0xf2efe0 奶油色块）和 'SPECIMEN' 标签都放在 x=-.68 的左侧，而通光孔在载物台正中央（x=0），标本没对准光孔、偏离光路中心。

【修改要求】
1. 给玻片新建一个**专用玻璃材质**（不要复用透射用的 M.glass），改成"半透但看得出是玻璃片"：
   `slideGlassMat = new THREE.MeshPhysicalMaterial({color:0xcfe4e4,transparent:true,opacity:.5,roughness:.08,metalness:0,side:THREE.DoubleSide,depthWrite:true})`
   → 关键：`opacity` 提到 .45~.55、`depthWrite:true`，让玻片边缘/面能正常遮挡、呈现玻璃质感；slideGlass 改用此材质。
2. 标本与盖玻片放正中（x=0，对准通光孔）：
   - 盖玻片：一块薄小方片（如 box(.5,.010,.5, slideGlassMat 或高透材质)) 在 [0,.022,0]；
   - 标本：一块小块染色样品（如 box(.34,.012,.30, 半透明染色色 0x6b5a9e 或 0x4a6fa5，roughness .6）放在盖玻片下 [0,.014,0]，正好对准光孔中心。
3. 标签移到一侧：'SPECIMEN' 标签放到左端（x≈-.68, y≈.028），只作为玻片左侧的标签贴纸，不再和标本混在中心。
4. 保留 slide 随 xRail/yRail 的移动、`slide.visible=state.specimen!=='none'` 的显隐联动。

═══════════════ 四、验收 ═══════════════

1. 分光头：上窄下宽的对称梯形棱镜盒，无中间鼓包，左右对称，与下方脖子、上方瞳距桥平滑衔接，不再歪斜错位；
2. 目镜镜筒：实体白色、两端封闭，从任何角度看不到筒内空洞，眼睛透镜严丝合缝填住顶端；
3. 装片：玻片看得出是玻璃实体（不再隐形），盖玻片+染色标本居中对准通光孔，'SPECIMEN' 标签在左侧；
4. eyepiece 的 ipd/diopter、slide 的随动与显隐，均在改动后保持正常。
