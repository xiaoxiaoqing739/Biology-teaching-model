# 显微镜装片图像更改说明

> 整理日期：2026-09-23  
> 适用项目：「双目电光源显微镜 3D 交互模拟」

## 1. 当前装片功能是怎么做的

当前网页并没有加载真实显微照片，而是使用 Canvas 程序实时绘制模拟图像。

- `index.html` 中的下拉菜单定义了人血涂片、口腔上皮、洋葱表皮、水绵、草履虫和「上」字玻片。
- `main.js` 中的 `makeSpecimen(type)` 根据标本类型绘制形状、颜色和分布。
- `drawOptics()` 把绘制结果放入圆形显微镜视野，并添加：
  - 180° 倒像；
  - 物镜和目镜倍率缩放；
  - 玻片移动时的反向像移；
  - 粗、细准焦导致的模糊变化；
  - 电源、亮度、光圈和聚光镜导致的明暗变化；
  - 圆形裁切和边缘暗角。
- `physics.mjs` 负责倍率、清晰度、亮度和图像位移计算。

## 2. 讨论过的多倍率图像方案

### 方案 A：每种物镜分别提供图片

为每种标本提供 4×、10×和 40×物镜图片。

问题：如果三张图片是独立拍摄的，它们通常不在同一坐标系中。低倍找到的区域，切换高倍后可能跳到另一个位置；高倍也无法在整个低倍范围内移动。

### 方案 B：多分辨率图像金字塔

使用高倍网格照片拼接成覆盖整个低倍范围的超高分辨率母图，再生成低、中、高三层图像。

优点：

- 所有倍率共享同一坐标系；
- 低倍定位后切换高倍，仍是同一个标本位置；
- 高倍可在整个低倍区域内移动。

问题：需要拍摄和拼接大量高倍照片，当前拍摄条件难以满足。

## 3. 最终选定的方案

每种标本只提供一张「10×目镜 + 4×物镜」拍摄的高分辨率原图，程序通过裁切和缩放模拟更高倍率。

- 4×物镜：显示原图的较大范围。
- 10×物镜：裁取约 40% 的线性范围后放大。
- 40×物镜：裁取约 10% 的线性范围后放大。
- 5×、10×、16×目镜：在当前物镜图像基础上继续数字缩放。
- `slideX/slideY` 保持统一玻片坐标，切换物镜时不改变观察中心。

该方案的优点是坐标连续、素材要求低，适合教学 Demo。

## 4. 必须接受的局限

数字放大只能放大原图中已有的像素，无法产生真实 10×或 40×物镜才能观察到的新细节。

可以使用以下处理改善观感：

- 高质量插值缩放；
- 轻度锐化；
- 局部对比度补偿；
- 避免过度锐化和 AI 虚构细胞结构。

因此，高倍结果应定位为「教学模拟」，不宣称为真实 400×显微成像。

## 5. 需要提供的图片素材

每种标本提供一张原始图片，尽量满足：

- 10×目镜 + 4×物镜拍摄，总倍率 40×；
- 使用相机或手机的原始文件，不要使用聊天软件压缩图或截图；
- 建议至少 `3000×3000` 像素，分辨率越高越好；
- 对焦清晰，光照和曝光均匀；
- 标本主体位于画面中央；
- 不要添加文字、箭头、比例尺或水印；
- 可以保留圆形目镜边缘，后期可以裁切；
- 每张图注明标本名称、目镜倍率和物镜倍率。

推荐命名：

```text
blood-objective-4x-original.jpg
cheek-objective-4x-original.jpg
onion-objective-4x-original.jpg
```

素材说明模板：

```text
文件：blood-objective-4x-original.jpg
标本：人血涂片
目镜：10×
物镜：4×
是否允许裁切：是
是否允许调色：是
是否允许轻度锐化：是
图片来源/版权：自拍
```

## 6. 后续开发时的改造步骤

1. 在项目中建立标本图片目录，例如 `assets/specimens/`。
2. 建立标本配置表，将下拉菜单的 `value` 映射到图片文件。
3. 预加载标本图片，未加载完成时显示等待状态。
4. 用真实图片替换 `makeSpecimen(type)` 的程序绘图。
5. 使用统一的归一化玻片坐标，例如 `0～1`。
6. 根据物镜倍率计算原图裁切范围。
7. 将裁切范围绘制到 `scopeCanvas`，保留倒像、调焦、亮度和暗角效果。
8. 限制玻片移动边界，防止裁切区域超出原图。
9. 切换物镜时保持观察中心不变。
10. 添加高质量插值和可控制的轻度锐化。
11. 更新脚本缓存版本号，避免浏览器继续加载旧代码。

## 7. 裁切与倍率的基本关系

以4×物镜图片为完整坐标范围：

```js
const objectiveFovScale = {
  4: 1,
  10: 4 / 10,
  40: 4 / 40
};
```

假设原图宽高为 `W/H`，当前中心为 `centerX/centerY`：

```js
const scale = objectiveFovScale[state.objective];
const cropW = W * scale;
const cropH = H * scale;
const cropX = centerX * W - cropW / 2;
const cropY = centerY * H - cropH / 2;

ctx.drawImage(
  image,
  cropX, cropY, cropW, cropH,
  0, 0, 640, 640
);
```

实际开发时需结合图片长宽比、圆形视野和移动边界进一步调整。

## 8. 验收标准

- 选择标本后加载对应真实图片。
- 4×、10×、40×物镜切换时，观察中心不跳动。
- 物镜倍率越高，显示的原图范围越小。
- 移动玻片时，视野中图像按显微镜成像规律反向移动。
- 图像不越界，不出现透明空白区域。
- 粗、细调焦模糊效果保留。
- 电源、亮度、光圈和聚光镜的明暗联动保留。
- 目镜倍率仍能改变总倍率和视觉缩放。
- 40×物镜模式下尽可能保持清晰，但不伪造原图不存在的生物细节。
