## 补充：载物台 / 压片夹 / 横纵手轮 三者关系修复提示词（可整段复制）


## 补充：遮光器（虹膜光圈）形状与开合修复提示词（可整段复制）

```text
继续修 model.js 的虹膜光圈(diaphragm)。当前实现是 10 片等距环段，动画用
blades.forEach(b=>b.scale.setScalar(1+state.aperture*.11)) 做「整体缩放」，
这不是真实虹膜光圈的形状与开合方式，必须重构。

══════ 一、真实虹膜光圈原理（你要达到的效果）══════
虹膜光圈由多片（本模型 10 片）新月形薄金属叶片组成：
- 每片叶片是「偏心月牙形」：外弧半径较大（铰接在固定环上），内弧半径小（围成中央光孔）；
- 叶片绕中心螺旋重叠排列，每片间隔 36°；
- 开合时叶片绕各自铰点旋转，外缘固定不动，只有内缘轮廓改变 → 中央孔径连续变化；
- 孔径形状是「正十边形近似圆」，始终与光轴同心，叶片间有重叠、无缝隙、无穿插。

══════ 二、按下面重构叶片几何 ══════
1. 叶片形状（偏心月牙，覆盖角必须大于间距角才会重叠）：
   const a0=-0.36, a1=0.36;                       // 约 ±20.6°，总覆盖 ≈41° > 36°(间距)
   shape.absarc(0,0,.43, a0, a1, false);          // 外弧 r=.43
   shape.lineTo(Math.cos(a1)*.04, Math.sin(a1)*.04); // 连到内弧端点
   shape.absarc(0,0,.04, a1, a0, true);           // 内弧 r=.04（反向）
   shape.closePath();
2. 每片叶片单独一个 group g：g.rotation.y = i*Math.PI/5（i=0..9，36° 等距）；
   叶片 mesh 在 g 内 rotation.x=-Math.PI/2 平放；
   给每片一个微小 Y 偏移（如 -0.012*i/10）实现层叠、避免同高度穿插。
3. 保存每片叶片的原始顶点：b.userData.original = Float32Array.from(geometry.attributes.position.array)

══════ 三、改开合动画（替换 scale.setScalar）══════
每帧对每片叶片逐顶点修改内圈半径，外圈固定：
  leaves.forEach(b=>{
    const a=b.geometry.attributes.position, o=b.userData.original;
    for(let i=0;i<a.count;i++){
      const x=o[i*3], y=o[i*3+1], r=Math.hypot(x,y);
      const k = r < .10 ? (1 + state.aperture*1.1) : 1;   // 只缩放内圈顶点
      a.setXY(i, x*k, y*k);
    }
    a.needsUpdate=true;
  });
  保留拨杆联动 lever.rotation.y = -state.aperture*.18。

══════ 四、验收 ══════
1. aperture=0 时叶片重叠、中央孔接近闭合（约 r=.04）；
2. aperture=4 时内圈半径扩到约 .22，孔形为正十边形近似圆，仍与光轴同心；
3. 调光圈滑杆时叶片绕各自铰点旋转收放，外缘不动、叶片始终重叠无缝隙；
4. 无叶片穿插、无走样闪烁。
```

## 补充：来自实物视频的印证与微调（重要）

已核实作者「小草林林」的 16 秒实物演示视频《显微镜遮光器原理》，结论如下：

1. 遮光器 = 虹膜光圈，装在**载物台下方、聚光镜下方**，黑色圆盘，中央通光孔。
2. 叶片是**弧形弯月状、边缘为曲线**（非直边），约 5~6 片同心重叠；全开时孔呈正多边形近似圆，收缩时保持圆孔。
3. 侧方伸出一个**拨片（拨杆）**，转动拨片连续调节孔径；作者评论原话「有个拨片，转动」。
4. 外圈有**刻度环**：N.A. 1.25/0.9，以及 10× / 40× 等物镜匹配档位标记。
5. 演示字幕「光圈变大 视野变亮」——孔径越大进光越多、视野越亮。

据此对上面光圈提示词做 3 处微调（其余照旧）：
- **叶片数量**：10 片改为 **6~8 片**（更贴近实物，孔从六/八边形近似圆；若想要更圆也可保留 8 片，别用 10 片硬凑）。
- **拨片更明显**：拨片（lever）加长加粗，突出在光圈盘侧下方，选中高亮时可单独操作，动画 `lever.rotation.y = -aperture*0.18` 保留。
- **补刻度环**：在光圈盘外圈加一圈环形刻度文字——内环标 `N.A. 1.25`，外环按角度标 `4× / 10× / 40×`（用 CanvasTexture 淡色浅灰字，贴在光圈盘顶面外缘）。
