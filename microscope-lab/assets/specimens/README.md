## 3. 程序如何使用这些图

- 每张图映射到装片世界坐标中央 1600×1600 区域，即「10×目镜 + 4×物镜」的完整视野。
- 4×物镜（10×目镜）：显示整图，与实拍视野一致。
- 10×物镜：裁取约 40% 线性范围放大显示。
- 40×物镜：裁取约 10% 线性范围放大显示（数字放大，不虚构新细节，属教学模拟）。
- 5×/10×/16×目镜：在物镜视野基础上继续数字缩放。
- 图片外区域显示为空白载玻片底色（真实装片上材料只占玻片一小块）。
- 保留 180° 倒像、调焦模糊、光圈对比度联动、亮度联动、圆形视野与边缘暗角。
- 对实拍图统一应用轻度调色（`saturate(1.06)`，授权范围内）与高质量插值。

## 4. 维护约定

- 新增装片：将图片按拼音命名放入本目录，在 `main.js` 的 `PHOTO_SPECIMENS` 表和 `index.html` 下拉菜单各加一条，再重新打包 `offline-app.js` 并递增版本号。
- 请勿压缩或缩放本目录图片，保留原始分辨率（高倍裁切依赖原始像素）。
