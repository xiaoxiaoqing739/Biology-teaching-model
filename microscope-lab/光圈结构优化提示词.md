═══════════════ 二、重做 diaphragm（替换上面第 86 行整段）═══════════════

【2.1 层级与位置】
- 把 diaphragm 从 `group(condenserBody,[0,-.18,0])` 改挂到 **condenser 本体** 下，位置 `[0,-.42,0]`：
  `const diaphragm=group(condenser,[0,-.42,0]);`
  这样世界位置不变（condenser.y − .42 与原来 condenserBody 的 −.24、diaphragm 的 −.18 之和等价），但光圈在层级上独立于 condenserBody 的金属壳，作为聚光镜下方**单独可见的一层**。

【2.2 新增金属外圈 housing ring（真实光圈必备的固定座）】
- 在 diaphragm 原点加一圈**银灰色金属外圈**（用现成 `ring()` 辅助函数，它会自动 rotation.x=π/2 躺平）：
  - 外径约 .50、环宽约 .06 → 内径约 .44；
  - 材质 M.metal（银灰，与聚光镜壳一致）。
  `const housing=ring(.50,.06,M.metal,diaphragm,[0,0,0]);`
  (housing 仅作视觉外圈，不参与开合。)

【2.3 叶片结构：6 片、绕各自根部铆钉同步旋转】
替换 `leaves` 数组为 `irisPivots`（每个元素是一个承载叶片的 pivot group）。参考实现如下：

```
const IRIS_ROOT_R=.44;   // 叶片根部铆钉所在圆周半径（贴外圈内壁）
const IRIS_LEN=.50;      // 叶片从铆钉伸出的长度（足以盖到中心并略越过）
const IRIS_N=6;
const irisPivots=[],irisBase=[];
for(let i=0;i<IRIS_N;i++){
  const a=(i/IRIS_N)*TAU;
  // 根部铆钉 pivot：放在圆周上，Y 方向按 i 逐级下沉，形成叶片错位叠放
  const pivot=group(diaphragm,[Math.cos(a)*IRIS_ROOT_R,-(.05+i*.012),Math.sin(a)*IRIS_ROOT_R]);
  // 叶片形状：以 pivot 为原点、向 +X 方向延伸的扇形（半张角 30°）
  const s=new THREE.Shape();
  s.moveTo(0,0);
  s.absarc(0,0,IRIS_LEN,-Math.PI/6,Math.PI/6,false);
  s.closePath();
  const leaf=mesh(new THREE.ShapeGeometry(s,32),M.dark,pivot);
  leaf.rotation.x=-Math.PI/2;   // 躺平到水平面（XZ 平面）
  // 初始朝向：让叶片的尖端（扇形展开方向）在 aperture=0 时指向圆心，
  // 这样关闭时中心孔≈0。请按此目标标定 leaf 或 pivot 的初始 rotation.y（含 +a 补偿）。
  irisPivots.push(pivot);
  irisBase.push(/* 记录每个 pivot 在 aperture=0 时闭合姿态的 rotation.y 基准值 */);
}
```

朝向标定要点（关键）：
- 叶片在局部坐标系里沿「+X」展开；躺平后它在水平面内的指向由 pivot 的局部旋转决定。
- 因为 pivot 位于圆周角 a 处，需要把叶片的展开方向转到「指向圆心」，即让 pivot 的初始 rotation.y = a + 补偿角（补偿角按叶片 Shape 的实际朝向微调，通常 ±π/2 或 ±π），使 **aperture=0 时 6 片叶片尖端收拢、中心孔接近 0**。
- 旋转开合时，在基准值上叠加 `(state.aperture/4)*(Math.PI/3)`（每档 15°，共 60°），使叶片随 aperture 增大**向外摆开**、中心孔变大。

【2.4 拉杆 lever：加长 + 加凸耳 + 摆幅翻倍】
- 把 lever 改成长金属拨杆：`box(.70,.06,.08,M.metal,diaphragm,[.42,0,.12])`，并加一节金属凸耳（如 `cyl(.08,.10,M.metal,lever,[.32,0,0])` 或小 box）作为拨动端点，让从侧面/底部能清楚看到它在摆动。
- 位置保持在外圈 r≈.44 一侧；可保留原橡胶端头或改成金属凸耳。
